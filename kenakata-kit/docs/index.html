  2. WordPress অ্যাডমিনে Plugins → Add New Plugin → Upload Plugin চাপুন।
  3. ফাইল বেছে Install Now চাপুন। আগের ভার্সন থাকলে WordPress জিজ্ঞেস করবে "Replace current with uploaded", সেখানে Replace চাপুন। আপনার সেটিংস হারাবে না।
  4. Activate চাপুন। বাম মেনুতে Kenakata Kit দেখা যাবে।
টিপআপডেটের আগে Kenakata Kit → Tools (Export / Import) থেকে সেটিংস ফাইল ডাউনলোড করে রাখুন। কিছু উল্টাপাল্টা হলে Import করে আগের অবস্থায় ফেরত যেতে পারবেন।
ক্যাশ প্লাগিন থাকলেআপডেট বা সেটিং বদলানোর পর LiteSpeed Cache, WP Rocket বা Cloudflare-এর ক্যাশ মুছুন, নইলে পুরনো ডিজাইন দেখাতে পারে।

    3. চেকআউটে এই দুটোই বড় বাটন হিসেবে দেখাবে।
  2. পেমেন্ট: WooCommerce → Settings → Payments-এ Cash on delivery চালু করুন।
  3. দুটো পেজ:
    • "Thank You" (স্লাগ thank-you): Elementor-এ Order Confirmation উইজেট বসান।
    • "Track Order" (স্লাগ track-order): Order Tracking উইজেট বসান।
    • Elementor না থাকলে পেজে [kk_thank_you] আর [kk_order_tracking] লিখুন।

  • Kenakata Kit → Dashboard → Plugin language-এ বাংলা বেছে নিন। শুধু এই প্লাগিনের পেজ আর উইজেট বাংলা হবে, বাকি WordPress আগের মতো থাকবে।
  • Automatic রাখলে আপনার WordPress প্রোফাইলের ভাষা মেনে চলে (Users → Profile → Language-এ বাংলা দিলে বাংলা)।

কাস্টমার যা দেখে (সার্চ, পপআপ, ট্র্যাকিং, থ্যাংক-ইউ পেজ) তা সাইটের ভাষা মেনে চলে: Settings → General → Site Language বাংলা হলে বাংলায়, ইংরেজি হলে ইংরেজিতে। বাটন আর চেকআউটের লেখা (যেমন "Buy Now", "Confirm Order") সেটিংসে আপনি নিজে যা লিখবেন তা-ই দেখাবে।

Colours & design (রং ও ডিজাইন)

পুরো প্লাগিনের চেহারা এখান থেকে নিয়ন্ত্রণ হয়।

Product cards (প্রোডাক্ট কার্ড)

শপ, ক্যাটাগরি, ব্র্যান্ড, সার্চ রেজাল্ট, রিলেটেড প্রোডাক্ট: সব জায়গার প্রোডাক্ট এই কার্ডে দেখায়। মোবাইলে নাম কখনো দামের নিচে ঢাকবে না, কারণ নাম নির্দিষ্ট লাইনে কেটে "…" দেখায় আর সব কার্ড সমান উঁচু থাকে।

  • Card style: Bordered / Shadow / Flat।
  • Image shape: বর্গ বা লম্বা। সব প্রোডাক্টের ছবি একই মাপে দেখায়।
  • Image fit: "Whole image" দিলে বোতল বা বাক্সের কিছু কাটা যায় না।
  • Product name lines: ২ রাখা ভালো। লম্বা নামের জন্য ৩।
  • Badge text: -{percent}% দিলে "-১২%", {amount}৳ ছাড় দিলে "২০০৳ ছাড়", শুধু Sale দিলে "Sale"।
  • Buttons to show: পাশাপাশি, উপর-নিচে, শুধু Buy Now, শুধু Add to cart, বা কোনোটাই না।
  • Buttons on mobile: "Cart icon + Buy Now" দিলে ছোট স্ক্রিনে দুটো বাটন এক লাইনে আঁটে। কম্পিউটারেও কার্ড খুব সরু হলে (এক সারিতে ৫–৬টা) Add to cart নিজে থেকে আইকন হয়ে যায়।
  • Shop, category and brand pages: প্রতি পেজে কয়টি প্রোডাক্ট (Products per page), আর কম্পিউটার, ট্যাবলেট ও মোবাইলে এক সারিতে কয়টি।
  • Use this card for every product list: বন্ধ করলে থিম বা WooCommerce-এর নিজের কার্ড দেখায়, পাশে Buy Now বাটন যোগ হয়।
টিপElementor-এর Products Grid উইজেটে প্রতিটি সেকশন আলাদা করে সাজানো যায়। এখানকার সেটিং হলো ডিফল্ট।

Brands & categories (ব্র্যান্ড ও ক্যাটাগরি)

ব্র্যান্ড আর ক্যাটাগরি কার্ডের ডিফল্ট সেটিং। Elementor-এর Brands আর Categories উইজেটে প্রতিটি সেকশন আলাদা করে বদলানো যায়।

  • Card style: Card with border / No border / Round image + name / Logo only (ব্র্যান্ডের জন্য; লোগো না থাকলে নাম দেখায়)।
  • ছবি দেওয়া: Products → Brands (বা Categories) → এডিট → Thumbnail। ছবি না থাকলে নামের প্রথম অক্ষর দেখায়।
  • ক্যারোসেল:
    • একসাথে কয়টি দেখাবে (কম্পিউটার, ট্যাবলেট ও মোবাইলে আলাদা)।
    • Autoplay আর কত সেকেন্ড পর পর।
    • Loop, তীর আর ডট।

Buy Now Button

  • কীভাবে কাজ করে: Buy Now চাপলে প্রোডাক্টটি কার্টে যোগ হয়ে সরাসরি চেকআউট খোলে। প্রোডাক্ট পেজে quantity আর ভ্যারিয়েশন (সাইজ/রং) মেনে চলে।
  • Buy only this product: চালু করলে কার্টের আগের জিনিস সরে যায়। বেশি বিক্রির জন্য অনেক দোকান এটা বন্ধ রাখে।
  • প্রোডাক্ট কার্ডে: সব প্রোডাক্টে একই দুটো বাটন, Add to cart আর Buy Now ("Select options" আর দেখায় না)।
  • ভ্যারিয়েবল প্রোডাক্ট (সাইজ/রং):
    • প্রতিটি অপশনের ডিফল্ট দেওয়া থাকলে (Product data → Variations → Default Form Values): Add to cart সেই অপশনটা পেজ রিলোড ছাড়া কার্টে যোগ করে, আর Buy Now সরাসরি চেকআউটে নেয়।
    • ডিফল্ট না থাকলে, বা ডিফল্ট অপশন স্টকে না থাকলে: দুটো বাটনই প্রোডাক্ট পেজে নেয়, সেখানে কাস্টমার অপশন বাছবে।

Checkout (চেকআউট)

  • ঘর: নাম, ফোন, ঠিকানা, ডেলিভারি এরিয়া আর (চাইলে) ইমেইল। প্রতিটি ঘরের লেবেল আর হালকা লেখা বদলানো যায়।
  • দেশ: দেশের ঘর লুকানো থাকে; সব অর্ডার Country সেটিং অনুযায়ী ধরা হয়।
  • Delivery area: শিপিং মেথডগুলোই এরিয়া বাটন। নতুন এরিয়া (যেমন "ঢাকার আশেপাশে ১২০") যোগ করতে শিপিং সেটিংয়ে আরেকটা Flat rate যোগ করুন।
  • কার্ট পেজ: ডেলিভারি চার্জ শুধু তথ্য হিসেবে দেখায়; কাস্টমার এরিয়া বাছে চেকআউটে। এরিয়া বাছার আগে মোট টাকা লুকানো থাকে।
  • ভুলের মেসেজ: পরিষ্কার একটাই মেসেজ দেখায়, যেমন "Full name is a required field."।
  • Promo code (coupon) field: কার্ট আর চেকআউট দুটোতেই / শুধু চেকআউটে / শুধু কার্টে / কোথাও না। কোনো অফার না চললে লুকিয়ে রাখুন। WooCommerce-এ কুপন চালুই থাকে, তাই পরে আবার দেখানো যায়।
মনে রাখুনসহজ চেকআউট WooCommerce-এর "ক্লাসিক" চেকআউটে কাজ করে (শর্টকোড [woocommerce_checkout] বা Elementor-এর Checkout Form উইজেট)। ব্লক চেকআউট ব্যবহার করলে Checkout পেজটা ক্লাসিক শর্টকোডে বদলে নিন।

Fake-order protection (ভুয়া অর্ডার সুরক্ষা)

  • Phone number check: "Exactly 11 digits" দিলে কাস্টমার ১১টার বেশি সংখ্যা টাইপই করতে পারে না। ভুল নম্বরে (১০ সংখ্যা, +880, অক্ষর) অর্ডার হয় না। চেকআউট, ট্র্যাকিং আর রেজিস্ট্রেশন তিন জায়গায় কাজ করে।
  • Repeat-order block: একই নম্বর থেকে নির্দিষ্ট মিনিটের মধ্যে দ্বিতীয় অর্ডার নেওয়া হয় না (ডিফল্ট ৩০)। আগের অর্ডার Cancelled বা Failed হলে আবার অর্ডার করা যায়। মেসেজে {minutes} = বাকি সময়, {order} = আগের অর্ডার নম্বর।
  • Also block the same internet connection (IP): সাবধানে চালু করুন; একই মোবাইল অপারেটরের অনেক কাস্টমারের IP একই হতে পারে।
  • Never block admins / shop managers: আপনি নিজে ফোনে অর্ডার নিয়ে বসাতে পারবেন।

Thank-you page (থ্যাংক-ইউ পেজ)

  • কী দেখায়: অর্ডারের পর কাস্টমার আপনার বানানো পেজে যায়। সেখানে অর্ডার নম্বর, তারিখ, মোট টাকা, প্রোডাক্ট, ঠিকানা আর "Track your order" বাটন থাকে।
  • শিরোনামে নাম: শিরোনামে {name} লিখলে কাস্টমারের নাম বসে যায়।
  • নিরাপত্তা: অর্ডারের গোপন key ছাড়া কেউ অন্যের অর্ডার দেখতে পারে না।

Order tracking & courier (অর্ডার ট্র্যাকিং ও কুরিয়ার)

কাস্টমার ট্র্যাকিং পেজে ফোন নম্বর দিলে শেষ ১০টা অর্ডার আর প্রতিটির অবস্থা (Received → Processing → With courier → Delivered) দেখে।

কুরিয়ার লিংক যোগ করা (প্রতিদিনের কাজ)

  1. WooCommerce → Orders থেকে অর্ডারটা খুলুন।
  2. ডান পাশের Courier & tracking বক্সে কুরিয়ার বাছুন (Steadfast, Pathao…), কনসাইনমেন্ট আইডি আর ট্র্যাকিং লিংক দিন।
  3. Update চাপুন। "Mark as Shipped when a tracking link is saved" চালু থাকলে:
    • অর্ডার Shipped হয়ে যাবে।
    • কাস্টমার লিংকসহ একটা নোট পাবে।
    • ট্র্যাকিং পেজে "Track parcel" বাটন দেখাবে।

কুরিয়ারের লাইভ স্ট্যাটাস (Pro)

Live courier status চালু করলে, Courier booking দিয়ে পাঠানো অর্ডারে কাস্টমার ট্র্যাকিং পেজে "কুরিয়ার বলছে: …" দেখবে (Steadfast, Pathao, RedX, eCourier)। কুরিয়ারকে জিজ্ঞেস করা হয় শুধু কাস্টমার দেখলে, এক অর্ডারে ৩০ মিনিটে একবার। Mark the order Completed… চালু থাকলে কুরিয়ার "Delivered" বললে অর্ডার Completed হয়ে যায়।

Couriers I use (যেসব কুরিয়ার ব্যবহার করি)

বাংলাদেশের ১৮টি কুরিয়ারের তালিকা আছে (Steadfast, Pathao, RedX, Paperfly, eCourier, CarryBee, Delivery Tiger, Sundarban, SA Paribahan, Karatoa, Janani, Continental, AFS, Sheba, Navana, বাংলাদেশ পোস্ট, নিজের ডেলিভারি ম্যান, অন্যান্য)। যেগুলো ব্যবহার করেন সেগুলোতে টিক দিন: অর্ডারে শুধু এগুলোই আসবে।

  • ট্র্যাকিং আইডি লিখলে লিংক নিজে থেকে তৈরি হয় (Steadfast, Pathao, RedX)। অন্য কুরিয়ারের ঘরে নিজের লিংক দিতে পারেন, আইডির জায়গায় {id} লিখে।
  • তালিকায় নেই? Other couriers ঘরে প্রতি লাইনে key|নাম|লিংক লিখুন।
  • Also ask for the order number চালু করলে শুধু ফোন নম্বর জেনে কেউ অন্যের অর্ডার দেখতে পারবে না: ফোন + অর্ডার নম্বর দুটোই লাগবে।

Store dashboard (স্টোর ড্যাশবোর্ড)

দোকান চালানোর জন্য আলাদা, হালকা একটা পাতা: yoursite.com/dashboard। wp-admin খুলতে হয় না, ফোনে সহজে চলে। এখানে থিম, Elementor বা অন্য প্লাগিনের ফাইল লোড হয় না, তাই খুব দ্রুত খোলে। দোকানের সাধারণ পাতায় এর কোনো ফাইল যায় না।

চালু করা

  1. Kenakata Kit → Store dashboard খুলুন।
  2. Turn on the store dashboard সুইচটা চালু করুন। ডিফল্টে এটা বন্ধ থাকে, তাই আপডেট করলে সাইটে কিছু বদলায় না।
  3. ঠিকানাটা (যেমন yoursite.com/dashboard) ফোনের হোম স্ক্রিনে বুকমার্ক করে রাখুন।

এখানে কী কী করা যায়

  • Home: আজ, ৭ দিন আর ৩০ দিনের বিক্রি ও অর্ডার। "নজর দিতে হবে" অংশে নতুন অর্ডার, স্টক কম আর স্টক শেষ।
  • Orders: স্ট্যাটাস বদলানো, Call ও WhatsApp বোতাম, কুরিয়ার ও ট্র্যাকিং, নোট, ক্রেতার আগের অর্ডারের ইতিহাস।
  • Products: নাম, দাম, সেল প্রাইস, স্টক, ছবি, ক্যাটাগরি, বিবরণ বদলানো আর নতুন প্রোডাক্ট যোগ করা।
  • Blog: পোস্ট লেখা, ছবি বসানো, ড্রাফট রাখা বা প্রকাশ করা।

টিমের লোককে দেওয়া

  1. Users → Add New User থেকে ইউজার বানান, রোল দিন Store Manager (Kenakata)।
  2. এই রোল শুধু অর্ডার, প্রোডাক্ট, ছবি আর ব্লগ সামলাতে পারে। সেটিংস, প্লাগিন বা থিম ছুঁতে পারে না।
  3. চাইলে Keep Store Managers out of WordPress admin চালু রাখুন: তাহলে তারা wp-admin খুললে ড্যাশবোর্ডে ফিরে আসবে।

লগইনের পর কোথায় যাবে ৩.৭.০-এ নতুন

Kenakata Kit → Store dashboard → After login, go to থেকে বাছুন:

  • Dashboard for Store Managers only (ডিফল্ট): শুধু Store Manager লগইন করলে ড্যাশবোর্ডে যায়। অ্যাডমিনিস্ট্রেটর আর শপ ম্যানেজার আগের মতোই wp-admin-এ যান।
  • Dashboard for the whole team: অ্যাডমিনিস্ট্রেটর, শপ ম্যানেজার আর Store Manager, সবাই লগইনের পর সরাসরি ড্যাশবোর্ডে যান।

সাধারণ কাস্টমারদের কিছুই বদলায় না, তারা আগের মতো যেখানে যেতেন সেখানেই যান। কেউ নির্দিষ্ট কোনো পাতার লিংক (যেমন wp-admin-এর Plugins পাতা) থেকে লগইন করতে এলে সেই পাতাতেই যান। wp-admin দরকার হলে ড্যাশবোর্ডের More মেনুতে WordPress admin লিংক আছে।

More insights: চাপ দিলে লোড হয় ৩.৭.০-এ নতুন

হোম পেজের নিচে তিনটা বাক্স আছে। প্রতিটার Show চাপলে তবেই সেটার হিসাব আসে। না চাপলে কিছু লোড হয় না, তাই ড্যাশবোর্ড দ্রুত থাকে।

  • Sales trend: দিন ধরে বিক্রির স্তম্ভচার্ট, মোট বিক্রি, অর্ডারের সংখ্যা আর গড় অর্ডার। ৭ দিন বা ৩০ দিন বাছা যায়। আজকের স্তম্ভটা দ্বিতীয় রঙে দেখায়।
  • Best-selling products: গত ৩০ দিনে সবচেয়ে বেশি বিক্রি হওয়া ৫টা প্রোডাক্ট।
  • Cash with couriers: Shipped স্ট্যাটাসের ক্যাশ অন ডেলিভারি অর্ডারের মোট টাকা, মানে কুরিয়ারের কাছ থেকে আপনার এখনো পাওয়ার বাকি। সাথে পার্সেল কয়টা পথে আছে আর সবচেয়ে পুরোনোটা কত দিন আগের।
জেনে রাখুনহিসাব ৫ মিনিট মনে রাখা হয়। অর্ডার আসলে বা স্ট্যাটাস বদলালে নতুন করে হিসাব হয়। সর্বশেষ ৩,০০০টা অর্ডার পর্যন্ত গোনা হয়। "Cash with couriers" দেখাতে Order tracking & courier-এ Shipped স্ট্যাটাস চালু থাকতে হবে।

Courier booking (এক চাপে কুরিয়ারে পাঠানো)

একবার কুরিয়ার বেছে তার API কী বসিয়ে দিলে, প্রতিটা অর্ডারে একটা Send to Steadfast-এর মতো বোতাম আসে। চাপলে পার্সেল বুক হয়, ট্র্যাকিং নিজে সেভ হয়, অর্ডার Shipped হয়ে যায়, আর ক্রেতাকে ট্র্যাকিং লিংক জানানো হয় (Order tracking & courier-এর নোটিফিকেশন সুইচ চালু থাকলে)। বোতাম পাবেন স্টোর ড্যাশবোর্ডের অর্ডারে আর WooCommerce-এর অর্ডার পাতায় Courier & tracking বাক্সে।

সেটআপ (শুধু অ্যাডমিনিস্ট্রেটর, একবারই)

  1. Kenakata Kit → Courier booking খুলুন।
  2. যে কুরিয়ার ব্যবহার করেন তার সুইচ (যেমন Steadfast) চালু করুন। তখন তার তথ্যের ঘরগুলো নিচে খুলে যাবে।
  3. কুরিয়ারের মার্চেন্ট অ্যাকাউন্ট থেকে API key আর Secret key কপি করে বসান। কী দুটো গোপন থাকে: সেভ করার পর শুধু শেষ ৪টা অক্ষর দেখা যায়, আর সাধারণ সেটিংসের Export-এ যায় না।
  4. Save চাপুন, তারপর Test connection। এটা শুধু কুরিয়ারের কাছে ব্যালেন্স জানতে চায়, কিছুই বুক করে না। "Connected" এলে সেটআপ শেষ।

এখন Steadfast আর Pathao যোগ করা আছে। প্রতিটা কুরিয়ারের আলাদা সুইচ আছে, তাই এক বা একাধিক কুরিয়ার একসাথে চালু রাখা যায়। শুধু চালু আর পুরো সেট-আপ করা কুরিয়ারগুলোই ড্যাশবোর্ড ও অর্ডারে দেখায়: একটা কুরিয়ার চালু থাকলে একটাই বোতাম, দুটো চালু থাকলে দুটো বোতাম (যেটায় চাপবেন সেটাতেই যাবে)। আরও কুরিয়ার পরের ভার্সনগুলোতে আসবে। সেটিংস শুধু অ্যাডমিনিস্ট্রেটর বদলাতে পারেন। শপ ম্যানেজার আর Store Manager শুধু পাঠাতে পারেন।

Pathao-র জন্য আলাদা ধাপ

  1. Pathao সুইচটা চালু করুন।
  2. Pathao মার্চেন্ট অ্যাকাউন্টের Developers' API → API Credentials থেকে Client ID আর Client secret বসান। সাথে আপনার Pathao লগইনের ইমেইল আর পাসওয়ার্ড দিন। সবগুলো গোপন থাকে।
  3. Save চাপুন, তারপর Test connection। সফল হলে আপনার স্টোরগুলো নম্বরসহ দেখাবে (যেমন 123456 = My Store)।
  4. সেই নম্বরটা Store ID ঘরে বসিয়ে আবার Save করুন। Store ID না দিলে বোতাম আসবে না।
  • Pathao ঠিকানা থেকে জেলা, জোন আর এরিয়া নিজে ধরে নেয়, তাই এখানে আলাদা করে দিতে হয় না। তবে ঠিকানা অন্তত ১০ অক্ষরের হতে হবে (বাড়ি, রাস্তা, এলাকাসহ)।
  • শুধু পরীক্ষার জন্য Pathao-র টেস্ট সার্ভার চালু করার সুইচ আছে। আসল দোকানে এটা বন্ধ রাখুন।

কোনো কুরিয়ার চালু থাকলে অর্ডারে কুরিয়ারের নাম, ট্র্যাকিং আইডি আর ট্র্যাকিং লিংক হাতে লেখার ঘর থাকে না। অর্ডার কুরিয়ারে পাঠালেই এগুলো নিজে থেকে বসে যায়, আর "Open tracking page" বোতামে ট্র্যাকিং পাতা খোলে। কোনো কুরিয়ারই চালু না থাকলে আগের মতো হাতে লেখার ঘর থাকে। WooCommerce অর্ডার পাতার "Courier & tracking" বাক্সেও একই নিয়ম।

অর্ডার পাঠানো

  1. ড্যাশবোর্ডে অর্ডার খুলুন, Courier অংশের ওপরের Send to Steadfast চাপুন।
  2. একটা ছোট বক্সে নাম, ফোন, ঠিকানা আর যত টাকা নিতে হবে দেখাবে। ভুল থাকলে এখানেই ঠিক করুন। ক্রেতা আগেই টাকা দিয়ে থাকলে অঙ্ক 0 করুন।
  3. Send now চাপুন। কয়েক সেকেন্ডে অর্ডারে "Sent to Steadfast", ট্র্যাকিং কোড আর Shipped স্ট্যাটাস দেখা যাবে।
  • ক্যাশ অন ডেলিভারি অর্ডারে টাকার অঙ্ক নিজে থেকে বসে, যতক্ষণ না পেমেন্টের তারিখ সেভ হয় (Processing অবস্থায় থাকলেও)।
  • ভুল করে দুবার চাপলেও একটাই পার্সেল তৈরি হয়। আগেই পাঠানো অর্ডারে বোতাম থাকে না।
  • Refresh status চাপলে কুরিয়ারের কাছে পার্সেলের বর্তমান অবস্থা (Delivered, Cancelled ইত্যাদি) জানতে চাওয়া হয়। এটা নিজে নিজে চলে না, তাই দোকান ধীর হয় না।
  • কুরিয়ার পার্সেল বাতিল করে দিলে অর্ডারে আবার পাঠানোর বোতাম আসে।

কুরিয়ার চেক (পাঠানোর আগে ক্রেতাকে যাচাই)

Kenakata Kit → Courier booking → Turn on Courier check চালু করলে তবেই অর্ডারে ফোন নম্বরের নিচে Courier check বোতাম আসে (না চালালে কিছুই দেখায় না)। চাপলে এই ফোন নম্বরের আগের অর্ডারের হিসাব আসে: মোট কয়টা, কয়টা সফল, কয়টা বাতিল, আর সফলতার শতকরা হার। সাথে একটা ট্রাফিক লাইট:

রংমানেকী করবেন
সবুজভালো ইতিহাসক্যাশ অন ডেলিভারি দেওয়া যায়
হলুদমাঝামাঝিফোন করে অর্ডার নিশ্চিত করে পাঠান
লালঅনেক বাতিলআগে ডেলিভারি চার্জ (বা পুরো টাকা) নিন
ধূসরনতুন ক্রেতা বা এখনো সব পার্সেল পথেনতুন ক্রেতা হিসেবে ধরুন

সবুজ-লালের সীমা Kenakata Kit → Courier booking থেকে বদলানো যায় (ডিফল্ট: ৮০% বা বেশি সবুজ, ৫০%-এর নিচে লাল)। +৮৮০ দিয়ে লেখা আর ০১ দিয়ে লেখা একই নম্বর ধরা হয়। হিসাব চাপ দিলে তবেই হয়, পাতা খোলার সময় নয়।

সীমা জেনে রাখুনএই ভার্সনে হিসাবটা শুধু আপনার নিজের দোকানের অর্ডার থেকে আসে। অন্য দোকান বা অন্য কুরিয়ারের ইতিহাস আসেনি। ওটা BD Courier-এর মতো আলাদা সেবার API দিয়ে যোগ করার কাজ চলছে।

সমস্যা হলে

  • "Send to…" বোতাম আসছে না: Courier booking-এ কুরিয়ার বাছা আর দুটো কী-ই সেভ করা আছে কি না দেখুন, আর অর্ডার আগেই পাঠানো হয়েছে কি না।
  • "API key গ্রহণ করেনি": কী দুটো আবার কপি করে বসান। শুরুতে বা শেষে ফাঁকা জায়গা যেন না থাকে।
  • "সময়মতো উত্তর আসেনি": কুরিয়ারের অ্যাকাউন্টে গিয়ে দেখুন পার্সেল তৈরি হয়ে গেছে কি না। হয়ে থাকলে ট্র্যাকিং হাতে বসান, নইলে আবার পাঠান।
  • ঠিকানা বা ফোন নিয়ে আপত্তি: বক্সেই ঠিক করে আবার পাঠান। ফোন নম্বর ১১ সংখ্যার বাংলাদেশি মোবাইল নম্বর হতে হবে।

Incomplete orders (অসমাপ্ত অর্ডার)

যারা চেকআউট পর্যন্ত গিয়ে ফোন নম্বর লিখেছেন কিন্তু "অর্ডার করুন" চাপেননি, তাদের তালিকা। ফোন করলে অনেকে অর্ডার করে ফেলেন। এক চাপে তাদের কার্টকে অর্ডারে বদলানোও যায়।

চালু করা

  1. Kenakata Kit → Incomplete orders খুলুন।
  2. Save incomplete orders চালু করে Save চাপুন। ডিফল্টে এটা বন্ধ থাকে।
  3. চাইলে Count as left after (কতক্ষণ চুপ থাকলে "ছেড়ে গেছে" ধরা হবে, ডিফল্ট ১৫ মিনিট) আর Keep for (কত দিন রাখবে, ডিফল্ট ৩০ দিন) বদলান।

কীভাবে কাজ করে

  • ক্রেতা চেকআউট পাতায় লিখতে লিখতে একটা সঠিক ফোন নম্বর দিলে তার নাম, ফোন, ঠিকানা আর কার্ট আপনার সাইটেই সেভ হয় (অন্য কাউকে পাঠানো হয় না)। ফোন নম্বর না দিলে বা কার্ট খালি থাকলে কিছুই সেভ হয় না।
  • লেখা শেষ হওয়ার একটু পরে সেভ হয়, আর পাতা বন্ধ করলেও শেষ তথ্য চলে যায়।
  • ক্রেতা যতক্ষণ লিখছেন (ডিফল্ট ১৫ মিনিট) ততক্ষণ তালিকায় আসে না। এর মধ্যে অর্ডার করে ফেললে তালিকায় কখনো আসেই না।
  • পরে ওই নম্বর দিয়ে অর্ডার হলে (যেকোনো ফরম্যাটে, +৮৮০১… বা ০১…) আপনাআপনি "Ordered" হয়ে যায়।
  • আপনার বা আপনার টিমের নিজের পরীক্ষার চেকআউট তালিকায় ঢোকে না।

তালিকা দেখা ও কাজ করা

  1. ড্যাশবোর্ডের More মেনুতে (বা ডেস্কটপের পাশের মেনুতে) Incomplete orders খুলুন। সংখ্যা-ব্যাজ দেখায় কয়জন বাকি। হোমেও একটা সতর্কতা আসে।
  2. প্রতিটা কার্ডে নাম, কার্টের প্রোডাক্ট ও মোট টাকা, ঠিকানা আর Call / WhatsApp বোতাম আছে।
  3. ফোন করে Mark as called চাপুন। ক্রেতা নিশ্চিত করলে Make an order চাপুন: একটা ক্যাশ অন ডেলিভারি অর্ডার (Processing) তৈরি হবে আর স্টক কমবে। একই কার্ট থেকে দুবার অর্ডার হয় না।
  4. আর দরকার না থাকলে Dismiss চাপুন, ক্রেতা আবার লিখলেও তা ফিরে আসবে না।
  • To call / Called / Ordered / Dismissed / All ফিল্টারে আর ফোন বা নাম দিয়ে খুঁজে দেখা যায়।
  • ড্যাশবোর্ড ছাড়া WooCommerce → Incomplete orders পাতায় সাধারণ তালিকা আছে।
  • Make an order চাপলে শিপিং খরচ যোগ হয় না। দরকার হলে অর্ডার খুলে যোগ করুন।
গোপনীয়তাএই সুবিধা চালু করলে ক্রেতাদের নাম-ফোন অসমাপ্ত অবস্থাতেও আপনার সাইটে থাকে। আপনার গোপনীয়তা নীতিতে সেটা জানিয়ে রাখুন (WordPress → Privacy পাতায় একটা নমুনা লেখা নিজে থেকে যোগ হয়)। ব্যক্তি চাইলে WordPress-এর Export / Erase Personal Data টুলে (ইমেইল দিয়ে) তাঁর তথ্য বের করা বা মুছে ফেলা যায়।

সমস্যা হলে

  • তালিকায় কেউ আসছে না: সুইচ চালু আছে কি না, আর ক্রেতা একটা সঠিক বাংলাদেশি নম্বর (১১ সংখ্যা) দিয়েছেন কি না দেখুন। চেকআউটে আপনি নিজে অ্যাডমিন হিসেবে লগইন থাকলে সেটা ধরা হয় না, অন্য ব্রাউজারে (লগআউট অবস্থায়) পরীক্ষা করুন।
  • সঙ্গে সঙ্গে আসছে না: "Count as left after"-এর সময় পার হলে তবেই আসে।
  • ক্যাশ প্লাগিন: চেকআউট পাতার স্ক্রিপ্ট ছোট (প্রায় ২ KB) আর শুধু সেই পাতাতেই লোড হয়। চেকআউট পাতা ক্যাশ থেকে বাদ রাখা (WooCommerce-এর স্বাভাবিক নিয়ম) থাকলেই হয়।

  • লগইন: ফোন নম্বর বা ইমেইল দিয়ে।

Product page (প্রোডাক্ট পেজ)

ভ্যারিয়েশন বাটন (সাইজ, রং…)

  • কী করে: ড্রপডাউনের বদলে প্রতিটি অপশন (যেমন S, M, L) একটা বাটন হিসেবে দেখায়। পাশে বাছাই করা মানটাও লেখা থাকে ("Size: M")।
  • স্টকে নেই এমন কম্বিনেশন: ধূসর আর কাটা দাগ দেওয়া থাকে, চাপা যায় না। যেমন L সাইজ বাছলে L-এ যে রং নেই সেটা ধূসর হবে।
  • আবার চাপলে: বাছাই উঠে যায়। "Clear" লিংক সব অপশন মুছে দেয় (চাইলে লুকানো যায়)।
  • সেটিং: Product page → Show options as buttons, বাটনের উচ্চতা আর কোণ। রং প্রধান রং অনুযায়ী। Add to Cart Form উইজেটে প্রতিটি রং, লেখা আর মাপ আলাদা করে বদলানো যায়।
  • কোথায় কাজ করে: থিমের প্রোডাক্ট পেজ, Elementor Pro-র "Add to Cart" উইজেট আর আমাদের "Add to Cart Form" উইজেট, সব জায়গায়।

প্রোডাক্টের বিবরণ (ইমপোর্ট করা প্রোডাক্ট)

  • সমস্যা: ইমপোর্টের সময় অনেক প্রোডাক্টের পুরো লেখা "Short description"-এ চলে যায় আর "Description" ফাঁকা থাকে। তখন লম্বা লেখা দামের পাশে বসে আর Description ট্যাব দেখায় না।
  • Long short descriptions go to the Description tab (ডিফল্টে চালু): এমন প্রোডাক্টে Description ট্যাবে পুরো লেখা দেখায়, আর দামের পাশে প্রথম কয়েক লাইন, সাথে "Read more" (চাপলে Description ট্যাব খোলে)। প্রোডাক্টের ডেটা বদলায় না।
  • যেসব প্রোডাক্টের নিজের Description আছে বা Short description ছোট, সেগুলো আগের মতোই দেখায়।

অর্ডারের বাটন ও তথ্য

  • "Order on WhatsApp" বাটন: Add to cart-এর নিচে বসে। প্রোডাক্টের নাম, দাম আর লিংক আগে থেকে লেখা থাকে ({product}, {price}, {url})।
  • "Call to order" বাটন
  • রং: WhatsApp বাটন, কল বাটন (খালি রাখলে প্রধান রং) আর এদের লেখার রং আলাদা করে বদলানো যায়।
  • Delivery information: শিপিং সেটিং থেকে চার্জ নিজে আসে, সাথে আপনার লেখা লাইন। বক্সের ব্যাকগ্রাউন্ড আর আইকনের রং বদলানো যায়।
  • Sticky Buy Now bar: মোবাইলে নিচে স্ক্রল করলে ছবি, দাম আর Buy Now আটকে থাকে। এ সময় Bottom Bar লুকিয়ে যায়, ফলে দুটো একসাথে দেখায় না। ভ্যারিয়েবল প্রোডাক্টে সাইজ না বাছলে উপরে সাইজ বাছার জায়গায় নিয়ে যায়।
Elementor দিয়ে প্রোডাক্ট পেজ বানালেElementor টেমপ্লেটে থিমের "summary" অংশ থাকে না, তাই এই বাটনগুলো নিজে থেকে আসে না। Add to Cart Form উইজেট বসান: এতে ভ্যারিয়েশন বাটন, পরিমাণ, Add to cart, Buy Now, WhatsApp/কল বাটন আর ডেলিভারি বক্স একসাথে থাকে। আলাদা জায়গায় চাইলে WhatsApp / Call Button আর Delivery Info উইজেট ব্যবহার করুন।

Reviews (ছবিসহ রিভিউ)

প্রোডাক্ট পেজের রিভিউ অংশ গোছানো আর সুন্দর করে। WooCommerce-এর নিজের রিভিউ ব্যবহার করে, তাই আগের রিভিউ, "verified owner" লেবেল আর Products → Reviews আগের মতোই কাজ করে।

  • রেটিং সারাংশ: বড় করে গড় রেটিং (যেমন ৪.৬), তারা, মোট রেটিং আর ৫ থেকে ১ তারার বার, পাশে "Write a review" বাটন।
  • কাস্টমারের ছবি: সব রিভিউয়ের ছবি উপরে এক সারিতে। ছবিতে চাপলে বড় করে দেখায়; ← → দিয়ে পরের ছবি, Esc দিয়ে বন্ধ।
  • রিভিউ কার্ড: নামের আদ্যক্ষর দিয়ে গোল অ্যাভাটার, তারা, নাম, তারিখ, লেখা আর ছবি।
  • রিভিউ ফর্ম: তারা বাছাই, লেখা আর "Choose photos" বাটন। ছবি বাছলেই ছোট প্রিভিউ দেখায়।

ছবি দেওয়ার নিয়ম (Photos in reviews)

  • কয়টা আর কত বড়: ডিফল্টে প্রতি রিভিউতে ৩টা, প্রতিটি ৩ MB পর্যন্ত। শুধু JPG, PNG আর WebP। বড় ছবি WordPress নিজে ছোট করে নেয়।
  • নিরাপত্তা: ভুয়া ফাইল (ছবির নামে অন্য কিছু), বেশি ছবি বা বড় ফাইল দিলে রিভিউ জমাই হয় না, একটা পরিষ্কার মেসেজ দেখায়।
  • কারা দিতে পারবেন: যারা রিভিউ দিতে পারেন সবাই / যারা প্রোডাক্টটা কিনেছেন (অর্ডারের ইমেইল মিলিয়ে) / শুধু লগইন করা কাস্টমার।
  • অনুমোদন: "Approve reviews with photos before they appear" চালু থাকলে (সাজেস্টেড) ছবিসহ রিভিউ Products → Reviews-এ Approve না করা পর্যন্ত দেখায় না। সেখানে রিভিউয়ের নিচে ছবিগুলোও দেখা যায়।
  • মুছে ফেলা: রিভিউ স্থায়ীভাবে মুছলে (Trash খালি করলে) তার ছবিও মিডিয়া লাইব্রেরি থেকে মুছে যায়।
  • কোথায় দেখায়: স্বাভাবিকভাবে প্রোডাক্ট ট্যাবের শেষ ট্যাব "Reviews (n)"-এর ভেতরে, এই নতুন ডিজাইনে। থিমের বা Elementor Pro-র Product Data Tabs, দুটোতেই কাজ করে।
  • Allow reviews on every product: ইমপোর্ট করা প্রোডাক্টে প্রায়ই প্রোডাক্টের নিজের "Enable reviews" বন্ধ থাকে, ফলে Reviews ট্যাবই দেখায় না। এটা চালু করলে সব প্রোডাক্টে রিভিউ চলে, প্রোডাক্ট না বদলেই। (WooCommerce → Settings → Products → Enable product reviews চালু থাকতে হবে।)
রিভিউ অন্য কোথাও চাইলেযেমন ল্যান্ডিং পেজে: Product Reviews উইজেট বসান। একই পেজে ট্যাবও থাকলে Reviews → Show reviews in the product tabs বন্ধ করুন, যেন রিভিউ দুবার না দেখায়।

Side cart (সাইড কার্ট)

  • খোলে: Cart Icon উইজেট, [kk_cart_icon] বা Bottom Bar-এর Cart-এ ক্লিক করলে, অথবা Add to cart চাপলে (চালু থাকলে)।
  • ভেতরে: প্রোডাক্ট, মোট টাকা, "View cart" আর "Checkout"।
  • বন্ধ করা: ✕ বাটন, বাইরে ক্লিক বা Esc কী।
  • চওড়া: Side cart width (৩০০–৬৪০px)। ফোনে প্রায় পুরো স্ক্রিন।
Elementor Pro-র Menu Cart ব্যবহার করলেওটারও নিজের সাইড কার্ট আছে। দুটো একসাথে চালু রাখবেন না।

Bottom Bar (মোবাইলের নিচের মেনু)

শুধু ফোনে, স্ক্রিনের নিচে অ্যাপের মতো আটকে থাকা মেনু। কম্পিউটারে দেখায় না।

  • কিছু ঢাকা পড়ে না: পেজের লেখা নিজে থেকে উপরে সরে যায়।
  • iPhone: নিচের হোম-বারের জায়গা রাখা হয়।
  • ভাসমান WhatsApp: বারের উপরে উঠে যায়।

চালু করা

  1. Kenakata Kit → Bottom Bar খুলুন (অথবা ড্যাশবোর্ডে Bottom Bar সুইচ)।
  2. Enable the bottom bar চালু করুন।
  3. Menu items অংশে আইটেম সাজান:
    • ক্রম বদলাতে: বামের ☰ ধরে টেনে নিন, অথবা ↑ ↓ চাপুন।
    • চালু/বন্ধ: প্রতিটি আইটেমের সুইচ দিয়ে।
    • Label, Icon, Link: প্রতিটি আইটেমে আলাদা বদলানো যায়।
    • Custom link: বাছলে URL-এর ঘর আসবে (যেমন অফার পেজ)।
    • ডিফল্ট আইটেম: Home, Shop, Cart, Account, Orders।
    • বন্ধ থাকা আইটেম: Categories, Search, Track, WhatsApp, Call আর ২টা নিজের লিংক। চালু করলেই দেখাবে।
    • কয়টা রাখবেন: ৫টার বেশি চালু করলে সতর্কবার্তা আসে। ফোনে ৪–৫টা সবচেয়ে ভালো।
  4. ডানের ফোন-প্রিভিউতে দেখে Save settings চাপুন।

Security (নিরাপত্তা)

  • Always use https: কেউ http:// দিয়ে এলে https://-এ পাঠায়। ভুলে সাইট আটকে না যায় তাই শুধু তখনই চালু হয় যখন আপনি নিজে https দিয়ে অ্যাডমিনে আছেন।
  • Hide admin user names: বাইরের লোক /wp-json/wp/v2/users বা ?author=1 দিয়ে আপনার লগইন নাম জানতে পারবে না।
  • Disable XML-RPC: Jetpack বা WordPress মোবাইল অ্যাপ ব্যবহার না করলে বন্ধ রাখুন। এতে pingback-এর অপব্যবহারও বন্ধ হয়।
  • Pause login after too many wrong passwords (ডিফল্টে চালু): একই সংযোগ থেকে ৬বার ভুল পাসওয়ার্ড দিলে (সংখ্যা বদলানো যায়) সেই সংযোগের জন্য ১৫ মিনিট লগইন বন্ধ থাকে। wp-login.php, My account, লগইন পপআপ আর XML-RPC সব জায়গায়। বাকি সবাই স্বাভাবিকভাবে লগইন করতে পারেন।
  • Browser security headers (চালু): অন্য সাইট আপনার দোকান ফ্রেমে দেখাতে পারে না (click-jacking), ব্রাউজার ফাইলের ধরন বদলে চালাতে পারে না, PHP ভার্সন লুকানো থাকে। "Always use https" চালু থাকলে HSTS-ও পাঠায়।
  • Hide the WordPress version (চালু)।
  • Turn off the theme/plugin code editor (চালু): পাসওয়ার্ড ফাঁস হলেও অ্যাডমিন থেকে কোড বদলানো যায় না। প্লাগিন/থিম আপডেট আগের মতোই চলে।
  • Block PHP files in the uploads folder: আপলোড ফোল্ডারে কোনো PHP ফাইল চলতে পারে না (ভাইরাস/ব্যাকডোর আটকাতে সবচেয়ে কাজের)। প্লাগিন বন্ধ করলে নিয়মটা নিজে থেকে মুছে যায়।
  • শুধু অ্যাডমিনিস্ট্রেটর: এই পেজের সেটিং শুধু Administrator বদলাতে পারেন; Shop manager বাকি সব সেটিং বদলাতে পারেন, এগুলো পারেন না।

প্লাগিনের ভেতরের নিরাপত্তা

  • সব ফর্ম আর AJAX-এ nonce আর অনুমতি যাচাই; সব ইনপুট পরিষ্কার করা (sanitize), সব আউটপুট escape করা। কোনো PHP ফাইল সরাসরি খোলা যায় না।
  • লগইন, রেজিস্ট্রেশন, ট্র্যাকিং আর ছবিসহ রিভিউয়ে সংখ্যার সীমা (rate limit)। Cloudflare থাকলেও আসল ভিজিটরের IP ধরা হয়, কেউ নকল হেডার দিয়ে ফাঁকি দিতে পারে না।
  • রিভিউয়ের ছবি: শুধু আসল JPG/PNG/WebP (ফাইলের ভেতর পরীক্ষা করে), সাইজ আর সংখ্যার সীমা।
  • আপডেটে সাইট ভাঙবে না: WooCommerce ৭.০-এর পুরনো হলে প্লাগিন নিজে বন্ধ থাকে। Elementor-এর ভবিষ্যৎ ভার্সনে দরকারি কিছু না থাকলে শুধু উইজেটগুলো সাময়িক বন্ধ হয়, অ্যাডমিনে একটা নোটিশ দেখায়; দোকান চলতে থাকে। তার উপরে WordPress-এর নিজের Recovery Mode আছে।

Speed & health (স্পিড ও হেলথ)

সব সুইচ শুরুতে বন্ধ। একটা চালু করার পর হোম, একটা প্রোডাক্ট, কার্ট আর চেকআউট একবার খুলে দেখুন, ক্যাশ প্লাগইন থাকলে ক্যাশ মুছুন।

  • হালকা পেজ: ইমোজি ও এমবেড স্ক্রিপ্ট সরানো, ব্লগ/সাধারণ পেজে WooCommerce-এর ফাইল না লোড করা, শান্ত Heartbeat।
  • Cloudflare Turnstile: লগইন, রেজিস্ট্রেশন আর চেকআউটে ফ্রি বট-যাচাই। dash.cloudflare.com → Turnstile থেকে দুটি কী এনে বসান। Cloudflare বন্ধ থাকলেও অর্ডার আটকায় না।
  • সাইট ও নিরাপত্তা চেকআপ: PHP ভার্সন, ক্যাশ, প্রতি পেজে লোড হওয়া সেটিংসের সাইজ, cron, https, "admin" ইউজার, ফাইল এডিটর, XML-RPC, প্লাগইন আপডেট। সমস্যা থাকলে পাশে "Fix →" লিংক।
  • ডাটাবেস পরিষ্কার: শুধু মেয়াদ শেষ অস্থায়ী ডাটা, পুরোনো কার্ট সেশন আর ৩০ দিনের পুরোনো স্প্যাম কমেন্ট মোছে। প্রোডাক্ট, অর্ডার, পেজ, পোস্টে হাত দেয় না।

Tools (Export / Import)

  • Export: সব সেটিং একটা .json ফাইলে ডাউনলোড হয়।
  • Import: সেই ফাইল দিলে হুবহু একই সেটিং বসে যায়। ভুল মান (যেমন সীমার বাইরের মাপ) নিজে থেকে ঠিক হয়ে যায়, অজানা কিছু বাদ পড়ে। ভুল ফাইল দিলে একটা মেসেজ দেখায়।
  • Reset everything: শুধু প্লাগিনের সেটিং মোছে। অর্ডার, প্রোডাক্ট আর পেজের কিছু হয় না; প্লাগিনের ভাষার পছন্দও থেকে যায়।

অপশনসহ প্রোডাক্ট (সাইজ, রং) Pro

  1. স্টোর ড্যাশবোর্ড → প্রোডাক্ট → নতুন প্রোডাক্ট। নাম লিখুন।
  2. "অপশনসহ" বাছুন। অপশনের নাম লিখুন (যেমন সাইজ), তারপর মান লিখে Enter চাপুন (S, M, L)। আরেকটা অপশন লাগলে "আরেকটা অপশন যোগ করুন" (যেমন রং)।
  3. "সব কম্বিনেশন বানাও" চাপুন। প্রতিটা কম্বিনেশনের দাম দিন, বা "সব অপশনে একই দাম বা স্টক" দিয়ে একবারে বসান। চাইলে প্রতিটার ছবি দিন।
  4. ক্যাটাগরি বা ব্র্যান্ড না থাকলে সেখানেই "+ নতুন ক্যাটাগরি / ব্র্যান্ড" চাপুন। তারপর সেভ।
টিপআগে ব্যবহার করা নাম আর মান টাইপ করার সময় সাজেশনে আসে, তাই সব প্রোডাক্টে একই বানান থাকে।

অর্ডার কনফার্ম ও কুরিয়ার Pro

  1. Kenakata Kit → Courier booking-এ যে কুরিয়ার ব্যবহার করেন সেটা চালু করে তার API তথ্য দিন (প্রতিটা ঘরের নিচে কোথায় পাবেন লেখা আছে, লিংকসহ)। "Test connection" চেপে দেখুন।
  2. নতুন অর্ডারে কাস্টমারকে কল বা WhatsApp করুন। সন্দেহ হলে Courier check চাপুন: এই নম্বরে আগে কতগুলো পার্সেল গেছে আর কতগুলো ফেরত এসেছে।
  3. কনফার্ম হলে "Send to Steadfast" (বা যে কুরিয়ার) চাপুন। ট্র্যাকিং নিজে থেকে বসে, অর্ডার Shipped হয়ে যায়।
  4. অনেক অর্ডার একসাথে: WooCommerce → Orders-এ টিক দিয়ে Bulk actions → "Send to …" (এক চাপে সর্বোচ্চ ১৫টা)।
  5. পার্সেলের খবর জানতে স্টোর ড্যাশবোর্ডের অর্ডার লিস্টে "কুরিয়ার Sync" চাপুন। ব্যাকগ্রাউন্ডে কিছু চলে না, তাই সার্ভারের উপর চাপ পড়ে না।

ইনভয়েস ও লেবেল প্রিন্ট ফ্রি

  1. Kenakata Kit → Invoice & label চালু করুন। দোকানের ফোন, ঠিকানা আর লেবেলের সাইজ বাছুন (থার্মাল 100×150, 75×100, বা সাধারণ প্রিন্টারে A4-এ ৬টা)।
  2. একটা অর্ডার: অর্ডারের পাতায় "Print invoice" / "Print label"।
  3. অনেকগুলো: স্টোর ড্যাশবোর্ডে স্ট্যাটাস বাছুন (যেমন Processing), তারপর "লেবেল প্রিন্ট"। অথবা WooCommerce → Orders → Bulk actions।
টিপপ্রিন্টের ঘরে "Margins: None" আর "Scale: 100%" রাখুন, তাহলে লেবেল ঠিক মাপে আসবে।

bKash / Nagad / Rocket ফ্রি

  1. Kenakata Kit → Mobile payment-এ নম্বর আর অ্যাকাউন্টের ধরন (পার্সোনাল / এজেন্ট / মার্চেন্ট) দিন। যে ঘর খালি, সেই ওয়ালেট দেখাবে না।
  2. কত নেবেন বাছুন: পুরো টাকা, অথবা শুধু ডেলিভারি চার্জ অগ্রিম (বাকি ক্যাশ অন ডেলিভারি)।
  3. ক্যাশ-আউট চার্জ (bKash ১.৮৫%, Nagad ১.৫%, Rocket ১.৮%, Upay ১.৪%) নিজে থেকে যোগ হয়; বদলাতে বা ০ করতে পারেন।
  4. অর্ডার এলে "On hold" থাকে। আপনার অ্যাপে TrxID আর টাকা মিলিয়ে "পেমেন্ট পেয়েছি" চাপুন (অর্ডারের পাতা বা স্টোর ড্যাশবোর্ড)। না পেলে "পাইনি"।
মনে রাখুনএটা ম্যানুয়াল: টাকা সত্যি এসেছে কিনা আপনাকেই অ্যাপে দেখে নিতে হবে। একই TrxID দুটো অর্ডারে চলে না।
পরিষ্কার ঠিকানাCheckout → District and thana চালু করলে কাস্টমার জেলা আর থানা তালিকা থেকে বাছে। কুরিয়ারে পাঠানোর সময় ঠিকানা নিয়ে ঝামেলা কমে।
কাস্টমারকে মেসেজMessages → Message templates for orders চালু করলে প্রতিটা অর্ডারে "কাস্টমারকে মেসেজ" বক্স আসে: লেখা বাছুন, এক চাপে WhatsApp। ফোন না ধরলে "ফোনে পাওয়া যায়নি" মেসেজটা কাজে লাগে।

ফেক অর্ডার শিল্ড ফ্রি

  • নম্বর ব্লক: Fake-order protection → Blocked numbers চালু করুন। তারপর যেকোনো অর্ডার থেকে "নম্বরটা ব্লক করুন"। ব্লক করা নম্বরের অর্ডার নেওয়া হবে না, বা শুধু অগ্রিম পেমেন্টে নেওয়া হবে।
  • বারবার ফেরত দিলে আগে পেমেন্ট: যাদের আগের অর্ডারের বেশিরভাগ বাতিল বা ফেরত, তাদের চেকআউটে ক্যাশ অন ডেলিভারি দেখাবে না। এর জন্য মোবাইল পেমেন্ট চালু থাকতে হবে।
  • নতুন কাস্টমার, অ্যাডমিন আর শপ ম্যানেজারের উপর কখনো প্রযোজ্য নয়।

৭. ধাপে ধাপে কাজ

হোমপেজে ব্র্যান্ড ক্যারোসেল বসানো ও সাজানো

  1. হোমপেজ Edit with Elementor দিয়ে খুলুন।
  2. বাম প্যানেলে "Brands" লিখে উইজেটটা টেনে সেকশনে বসান। পুরনো Shortcode উইজেট থাকলে মুছে দিন।
  3. Content → How many = 18, Order by = Most products first, Card style = Logo only (লোগো থাকলে) বা Card with border।
  4. Items per view: কম্পিউটারে 6, মোবাইল আইকন চেপে মোবাইলে 3।
  5. Carousel → Autoplay চালু, ৩ সেকেন্ড।
  6. Style → Card-এ ব্যাকগ্রাউন্ড, বর্ডার আর কোণ দিন। Update চাপুন।

শপ / ক্যাটাগরি / ব্র্যান্ড পেজ নতুন কার্ডে

  1. Templates → Theme Builder → Products Archive-এ টেমপ্লেট এডিট করুন।
  2. পুরনো "Archive Products" উইজেট সরিয়ে Products Grid বসান। Source = Products of this page।
  3. Columns: কম্পিউটারে 4, ট্যাবলেটে 3, মোবাইলে 2।
  4. প্রতি পেজে কয়টি দেখাবে তা Kenakata Kit → Product cards → Products per page-এ দিন।

মোবাইলে অ্যাপের মতো নিচের মেনু

  1. Kenakata Kit → Bottom Bar → Enable the bottom bar।
  2. Menu items-এ Home, Shop, Cart, Account, Orders রাখুন (ডিফল্ট)।
  3. Highlighted item = Cart, Style = Pill।
  4. Save settings, তারপর ফোনে সাইট খুলে দেখুন।

মোবাইলে প্রোডাক্টের নাম পুরোটা দেখাতে চাই

Product cards → Product name lines ৩ করুন, অথবা উইজেটে "Name lines" শুধু মোবাইলের জন্য ৩ দিন।

ছাড়ের ব্যাজ বাংলায় দেখাতে চাই

Badge text-এ দিন: {percent}% ছাড়। ফলাফল: "১২% ছাড়"।

চেকআউটের সব লেখা বাংলা করতে চাই

Kenakata Kit → Checkout-এ প্রতিটি লেবেল বাংলায় লিখুন, যেমন: "আপনার নাম", "মোবাইল নম্বর", "পুরো ঠিকানা", "ডেলিভারি এরিয়া"; অর্ডার বাটনে লিখুন "অর্ডার কনফার্ম করুন"। শিপিং মেথডের নামও বাংলা দিতে পারেন ("ঢাকার ভেতরে")।

প্রোডাক্ট পেজ (Single Product টেমপ্লেট) সাজানো

  1. Templates → Theme Builder → Single Product খুলুন।
  2. উপরের সারিতে তিনটা কলাম রাখুন: ছবি, তথ্য আর (চাইলে) পোস্টার। কলামের Width কম্পিউটারে ৩৮% / ৩৮% / ২৪%, ট্যাবলেটে ৪৮% / ৪৮% / ১০০%, মোবাইলে ১০০% দিন। মোবাইলে মান খালি রাখলে ট্যাবলেটের মান চলে, তখন ফোনে দুটো কলাম গাদাগাদি করে পাশাপাশি বসে।
  3. তথ্যের কলামে Product Title, Rating, Price, তারপর Add to Cart Form (থিমের Add to Cart-এর বদলে), তারপর Short Description।
  4. তার নিচে Elementor Pro-র Product Data Tabs: Description, Additional information আর শেষে Reviews, নতুন রিভিউ ডিজাইনসহ। ইমপোর্ট করা প্রোডাক্টের জন্য Reviews → Allow reviews on every product চালু রাখুন।
  5. সবার নিচে Products Carousel: Source = Related products, Section title = "Related Products"। আরেকটা: Source = Recently viewed, Section title = "Recently Viewed"।
  6. Elementor-এর উপরের মোবাইল/ট্যাবলেট আইকন দিয়ে দুটো ভিউ দেখে নিয়ে Update চাপুন।

৯. সমস্যা ও সমাধান

সেটিং বদলালাম, সাইটে কিছু বদলায়নি

  1. ক্যাশ মুছুন: ক্যাশ প্লাগিন, Cloudflare আর ব্রাউজার (Ctrl+F5)।
  2. Elementor উইজেটে নিজস্ব স্টাইল দেওয়া থাকলে সেটাই আগে চলে। উইজেটের Style-এ মানটা খালি করুন।

Bottom Bar দেখাচ্ছে না

  • Enable the bottom bar চালু আছে কি না, আর অন্তত একটা আইটেম চালু আছে কি না দেখুন।
  • শুধু Show on screens narrower than-এর চেয়ে ছোট স্ক্রিনে দেখায়। কম্পিউটারে দেখাবে না।
  • চেকআউট পেজে ডিফল্টে লুকানো থাকে।
  • WhatsApp/Call আইটেম নম্বর না দিলে দেখায় না।

চেকআউটে ডেলিভারি এরিয়া দেখাচ্ছে না

  • WooCommerce → Settings → Shipping-এ বাংলাদেশের জোনে অন্তত একটা শিপিং মেথড চালু আছে কি না দেখুন।
  • Country সেটিং Bangladesh আছে কি না দেখুন।
  • Checkout পেজ ব্লক চেকআউট হলে ক্লাসিক শর্টকোডে বদলান।

"An order was already placed…" মেসেজ আসছে

এটা ভুয়া অর্ডার সুরক্ষা: একই নম্বর থেকে ৩০ মিনিটের মধ্যে আরেকটা অর্ডার হচ্ছে। সত্যিকারের কাস্টমার হলে আগের অর্ডারে প্রোডাক্ট যোগ করে দিন, অথবা সময় কমান।

Buy Now বাটন কিছু প্রোডাক্টে নেই

স্টকে নেই এমন প্রোডাক্টে Buy Now দেখায় না। ভ্যারিয়েবল প্রোডাক্টে বাটন সবসময় দেখায়; ডিফল্ট অপশন না থাকলে প্রোডাক্ট পেজে নেয়। এক ক্লিকে কার্টে বা চেকআউটে নিতে প্রোডাক্টের Variations → Default Form Values-এ প্রতিটি অপশনের ডিফল্ট দিন।

কাস্টমার ছবিসহ রিভিউ দিয়েছেন, কিন্তু সাইটে দেখাচ্ছে না

"Approve reviews with photos before they appear" চালু থাকলে Products → Reviews-এ রিভিউটা Approve করুন। কাস্টমার নিজে অপেক্ষার মেসেজসহ তার রিভিউ দেখতে পায়।

প্রোমো কোডের ঘর দেখাচ্ছে না

Checkout → Promo code (coupon) field দেখুন। WooCommerce → Settings → General → Enable the use of coupon codes-ও চালু থাকতে হবে।

Brands উইজেট খালি

প্রোডাক্টে ব্র্যান্ড দেওয়া আছে কি না দেখুন (Products → Brands)। প্রোডাক্ট নেই এমন ব্র্যান্ড ডিফল্টে লুকানো থাকে।

থিমের সাথে বাটন অদ্ভুত দেখাচ্ছে

Colours & design → Strong styles চালু করুন।

কাস্টমার পাসওয়ার্ড ভুলে গেছে

পপআপের "Forgot password?" লিংক WooCommerce-এর পাসওয়ার্ড রিসেট পেজে নিয়ে যায় (ইমেইল লাগবে)। ইমেইল না থাকলে Users থেকে আপনি নতুন পাসওয়ার্ড দিন।

৩.২০.০

৩.১৯.০

  • লগইন করা অবস্থায় সাইড কার্টের উপরের অংশ অ্যাডমিন বারের নিচে ঢাকা পড়ত, ঠিক করা হয়েছে।

  • নতুন: ড্যাশবোর্ড → Site status-এ "নির্ধারিত কাজ (cron)" চলছে কি না দেখায়। ব্যাকআপ, নির্ধারিত সেল আর ইমেইল এর উপর নির্ভর করে। হোস্টিংয়ে cron job যোগ করার পর এখান থেকেই যাচাই করা যায়।

৩.৪.২

  • ঠিক করা: রিভিউ ফর্মে মাউস রাখলে বা রেটিং বাছলে তারার জায়গায় খালি বাক্স দেখাত।

৩.৪.১

  • ঠিক করা: Elementor-এর গ্লোবাল লিংক রং এই বাটনগুলোর লেখার রং বদলে দিত: "Write a review", "Load more", Buy Now উইজেট, কার্ট আইকন আর অ্যাকাউন্ট লিংক। ফলে সবুজ বাটনে সবুজ লেখা হয়ে লেখা দেখা যেত না।

৩.৪.০

  • রিভিউ আবার প্রোডাক্ট ট্যাবের শেষ ট্যাবে (নতুন ডিজাইনে)। নতুন সেটিং "Allow reviews on every product": রিভিউ বন্ধ থাকা ইমপোর্ট করা প্রোডাক্টেও রিভিউ চলে।
  • প্রোডাক্টের বিবরণ: পুরো লেখা Short description-এ থাকলে Description ট্যাবে দেখায়, দামের পাশে প্রথম লাইন আর "Read more"। এতে সিম্পল আর ভ্যারিয়েবল সব প্রোডাক্ট পেজ এক রকম দেখায়।
  • নিরাপত্তা:
    • ভুল পাসওয়ার্ডে লগইন সাময়িক বন্ধ; ব্রাউজার নিরাপত্তা হেডার; ভার্সন লুকানো।
    • কোড এডিটর বন্ধ; uploads-এ PHP আটকানো; XML-RPC পুরো বন্ধ।
    • Cloudflare-নিরাপদ IP; ছবিসহ রিভিউয়ের সীমা।
    • নিরাপত্তার সেটিং শুধু অ্যাডমিনিস্ট্রেটরের জন্য।
  • আপডেট-নিরাপত্তা: পুরনো WooCommerce-এ নিজে বন্ধ থাকে; Elementor-এর অমিল হলে শুধু উইজেট সাময়িক বন্ধ হয়, সাইট নয়।
  • ঠিক করা: Shop manager সেটিংস সেভ করতে পারতেন না।
